# Gold Price Analytics Project

This repository contains a complete data analysis mini-project based on a real gold price dataset.

## Files
- `Gold_Price_Analytics_Project.ipynb` - full Jupyter notebook
- `gold_analysis_dataset.csv` - cleaned and prepared dataset used in analysis
- `Gold_Price_Analytics_Submission.pdf` - final PDF submission
- `gold_monthly.csv` - original source dataset

## Dataset source
The original dataset is based on the `datasets/gold-prices` repository, which describes the data as monthly gold prices in USD since 1833.

## Project sections
- Problem statement
- Dataset description
- Data cleaning and statistics
- Visualizations
- Simple prediction model
- Insights and recommendations
